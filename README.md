# Webpack JS/HTML/CSS Template

To use this template, clone the repo and run `npm install`.

This template includes Prettier for formatting and Jest for testing.

## Scripts

- `npm run watch` — runs Jest in watch mode
- `npm test` — runs the test suite once
- `npm run build` - runs `webpack`
- `npm run dev` - tuns `webpack serve`

## Formatting

Prettier is configured via `.prettierrc` (currently empty). Format-on-save is enabled for VS Code via `.vscode/settings.json` — no extra setup needed.

## Testing

Tests live in `__tests__/`. Run `npm test` to execute them once, or `npm run watch` to re-run on file changes.
